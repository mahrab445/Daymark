# Daymark — Daily Routine Tracker

A matte-style daily routine tracker built with Flask, MongoDB Atlas, HTML, CSS and JavaScript.

## Features
- Register and log in
- Add tasks with a date and optional note
- Mark tasks complete / incomplete
- View tasks by date
- Daily total, completed, pending and completion percentage
- Edit and delete tasks
- Each account sees only its own tasks

## Setup

1. Install Python 3.10 or newer.
2. Open this project folder in a terminal.
3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate it on Windows:

   ```bash
   venv\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Copy `.env.example` to `.env`.
7. Paste your MongoDB Atlas connection string into `MONGO_URI`.
8. Replace `SECRET_KEY` with a long random value.
9. Run:

   ```bash
   python app.py
   ```

10. Open `http://127.0.0.1:5000` in your browser and create an account.

## MongoDB Atlas
- Create a free cluster.
- Create a database user and password.
- In Network Access, allow your development IP address.
- Copy the Python driver connection string and replace the username/password.
- Do not share or commit your `.env` file.

The database and collections are created automatically when the app first writes data.

## Deploy on Render

This repository includes a `render.yaml` Blueprint for a Python web service. To deploy:

1. In Render, choose **New → Blueprint** and connect `mahrab445/Daymark`.
2. In the Blueprint setup, provide `MONGO_URI` using your MongoDB Atlas connection string. Keep the database password in Render's environment settings; do not put it in this repository.
3. Apply the Blueprint. Render installs `requirements.txt` and starts the Flask app with Gunicorn. `SECRET_KEY` is generated by the Blueprint.
4. In MongoDB Atlas Network Access, allow the outbound IP ranges shown under your Render service's **Connect → Outbound** tab. Keep your database user password private.

The Render Blueprint uses the Singapore region and the free web-service plan. Free services can sleep when idle and may take a little time to wake up. See [Render's Flask deployment guide](https://render.com/docs/deploy-flask) and [outbound IP guide](https://render.com/docs/outbound-ip-addresses).
